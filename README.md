## About Me

I'm a Computer Science and Engineering student interested in the intersection of:

- Algorithms and problem solving
- Software engineering and system design
- Artificial Intelligence and Machine Learning
- Computer Vision and Deep Learning
- Computational mathematics and research
- Databases and backend systems
- Building practical systems from first principles

I prefer understanding **why something works** rather than treating a tool or abstraction as a black box.

> **Build → Understand → Experiment → Optimize → Repeat**
